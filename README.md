# SmartFlow AI

AI-powered junction optimization system for adaptive traffic control, emergency vehicle prioritization, congestion prediction, and intelligent traffic flow management.

---

## Features

- Real-time traffic density monitoring
- Adaptive traffic signal optimization
- Emergency ambulance priority system
- AI-based congestion prediction
- Lane-wise traffic analysis
- Dynamic signal timing control
- Smart traffic alerts
- Traffic analytics dashboard
- SQLite traffic logging system
- Animated junction simulation

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Backend
- Flask (Python)

### Database
- SQLite

---

## System Capabilities

### Adaptive Signal Control
The system dynamically adjusts green signal timing based on lane congestion levels.

### Emergency Vehicle Priority
Ambulances and emergency vehicles receive intelligent route prioritization using AI-based traffic control logic.

### Traffic Prediction
The system predicts congestion trends and generates proactive traffic alerts.

### Real-Time Monitoring
Traffic activity, congestion levels, lane density, and optimization logs are continuously monitored through the dashboard.
